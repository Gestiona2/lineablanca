# Publicación

Demo prevista: `https://demos.emp2web.com/lineablanca/`.

El script `scripts/publicar-demo.sh` compila con base `/lineablanca` y publica el resultado en la rama `gh-pages` del repositorio aislado `Gestiona2/lineablanca`. Requiere GitHub CLI autenticado como miembro de la organización.

No usar una publicación forzada ni apuntar a repositorios de otros demos. El cliente debe aprobar la vista previa antes de publicar.
