# Tecnologías y estructura

- Astro 7 con salida estática y Tailwind CSS 4 como herramienta de compilación.
- Estilos visuales propios en `src/styles/global.css`.
- Página de inicio: `src/pages/index.astro`.
- Layout compartido: `src/layouts/Layout.astro`.
- Contenido editable: `src/datos/inicio.json` y `src/datos/sitio.json`.
- Logo: `public/brand/logo-linea-blanca.png`.
- No se agregaron librerías de animación o iconos.
- Base de publicación de demo: `/lineablanca`.
