# Límites del sitio

- No inventar tarifas, cifras de experiencia, garantías, reseñas, certificaciones o acreditaciones de marcas. El sitio anterior menciona seis meses de garantía solo en el contenido de neveras; confirmar condiciones antes de ampliar esa afirmación.
- La frase “servicio técnico autorizado” del sitio anterior no se usa como afirmación de relación oficial; el aviso indica que no se representa a las marcas.
- El botón de WhatsApp prepara el chat; el visitante debe enviar el mensaje.
- No añadir formularios de datos personales, pagos o reserva confirmada sin backend y revisión legal.
- No modificar el repositorio o las credenciales de publicación compartidas sin autorización explícita de Emp2Web.
